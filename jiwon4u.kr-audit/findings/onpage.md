# On-Page SEO — 72/100

## 잘 되어 있는 것
- 모든 글 고유 title/description/H1 1개
- OG·Twitter Card 완비
- alt 누락 0건
- 글당 내부 링크 42~69개

## 발견 사항

| 심각도 | 항목 | 근거 | 조치 |
|---|---|---|---|
| High | 소개·개인정보처리방침 title이 'Latest Posts' | 테마 H1 빈 값, 개인정보처리방침 H1 14개 | 페이지 제목 입력, H1을 h2/p로 정리 |
| Medium | title 접미사가 김 | ' - 지원포유 - 클로드 활용 가이드' 21자로 제목 51~83자 | ' - 지원포유'로 축소 |
| Medium | 짧은 meta description 18개 | 45~62자 | 80~120자로 재작성 |
| Medium | 글 페이지 og:type=website | article이어야 함 | og:type=article, article:published_time 추가 |
| Low | 빈 article:author / twitter:site / twitter:creator | 값이 비어 있음 | 값 입력 또는 태그 삭제 |
| Low | 의미 없는 고정 페이지 URL | blog-page.html, blog-page_18.html | 새 URL로 옮기고 301 |
